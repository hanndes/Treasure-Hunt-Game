# 🗺️ Treasure Hunt Game

A grid-based treasure hunt game developed as a 2nd year Data Structures course project at FSM Vakıf Üniversitesi, built entirely in Java.

## 🧱 Data Structures Used

| Structure | Usage |
|---|---|
| Multi-Linked List | 2D game board grid |
| Binary Search Tree (BST) | Scoreboard sorting & retrieval |
| Stack | Move history (forward / backward) |

## 🎮 Gameplay
- Navigate a grid-based map to find treasures
- Avoid traps placed across the board
- Move forward or backward each turn
- Scores are saved persistently to `score.txt`

## 🖼️ Tech
- Java (JDK 8+)
- Java Swing — GUI
- Apache NetBeans

## ▶️ How to Run
1. Clone the repo
2. Open in Apache NetBeans
3. Build & run `BalciDereliMain.java`
